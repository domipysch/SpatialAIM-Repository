# Dataset curation

These 10 scripts will curate the datasets used in our experiments.
They will download the datasets and convert the data into the required format.
All but one work fully automatically: `curate_02_colorectal_cancer.py` takes its ST counts from the
raw Vizgen release, which needs a Google sign-in; the script prints what to download and asks for
the folder (or takes it from `--vizgen-dir`).
Five of them also write the cell segmentation mask of their ST slices to `ST/Segmentation/<slice>.tif`
and the matching `obs["segmentation_id"]` (02, 03, 04, 05, 09; shared code in `_segmentation.py`).
01, 06, 07, 08 and 10 have no public segmentation. The `Segmentation` column of `ST/index.csv` is maintained by hand, like the counts.
Only minor pre-processing (deleting near-empty columns etc.) has been applied.
No normalization or log operations are applied to the data, as we are working on raw counts.

These 10 script are fully generated by AI (Claude Opus 5.5).

## GUI use-case candidates (11-14)

`curate_11` to `curate_14` build candidate pairs for the GUI section (scRNA + imaging-based ST, all
Xenium with segmentation masks). They write to `Data/03_GUI`, not to `01_Datasets_Paper`, and are
not part of Experiment 1.

| Script | Pair(s) | Sources |
|---|---|---|
| `curate_11_human_crc.py` | `11_human-crc-p2`, `11_human-crc-p5` | Oliveira et al. 2025, Flex + 10x Xenium |
| `curate_12_human_ovarian_cancer.py` | `12_human-ovarian-cancer` (3 x 3 mm crop) | 10x Flex + Xenium Prime 5K |
| `curate_13_human_carotid_plaque.py` | `13_human-carotid-plaque` | Nat Commun 2025, Zenodo scRNA + GEO Xenium |
| `curate_14_mouse_kidney_iri.py` | `14_mouse-kidney-iri` | Kirita et al. 2020 snRNA + Humphreys lab Xenium |
